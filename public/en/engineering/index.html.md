# Sharing knowledge, shaping web culture.

> AI-native frontend engineering, a solid technical foundation, my web podcast Technikwürze and hands-on tutorials for HAWK students – how I pass on quality and experience.

For me, great engineering thrives on a solid technical foundation – on exchange with others, and on curiously trying out new tools such as AI agents. With the podcast *Technikwürze* and my tutorials at the HAWK, I create spaces for sharing knowledge – as a dialogue at eye level where we all learn from each other.

## AI-native Frontend Engineering

My AI-native workflow: on the left, the agent session in the editor; on the right, the result – this website.

Agents write the code, I steer the process – from the first specification to the final review. Behind it is a clearly structured workflow:

- **Spec-Driven Development:** Concepts and requirements take shape in dialogue with an agent and are precisely specified before the first line of code is written.
- **Context Engineering:** Project rules, architecture decisions, and documented knowledge give agents the context they need – versioned in the repository and more solid with every project.
- **Agent Skills:** Recurring workflows are encapsulated as reusable skills, for translation, operations, and maintenance, for example.
- **Multi-Agent Orchestration:** Specialized agents work in parallel, connected via MCP and plugins – model-agnostic, whether Claude, Codex, or Gemini.
- **Owning quality:** Automated tests, linting, and CI pipelines safeguard every step. My review has the final say.

This is how this website and the administration of my own infrastructure come about. Experience makes the difference: anyone who has known semantics, accessibility, and UX for decades sees immediately whether an agent has done clean work.

## Semantics. For Humans. For Machines.

Semantic HTML is no relic. What makes content accessible to screen readers also makes it interpretable for AI models. Clean markup of structure and meaning has always been the foundation of good frontend engineering – in the age of AI, it's more relevant than ever – agents, too, work better with clear structure.

For me, that's nothing new. Semantics has been part of my work from the start – and that's exactly what makes the difference: while others retrofit it, I've brought this quality for 30 years.

## Website Starter Kit

For my GT 1191 seminar at HAWK, I built my own starter kit. A single terminal command produces a fully pre-configured website – image optimization, web fonts, and less boilerplate included.

```bash
npm create website-starterkit
```

Three variants cover different learning goals: playground, one-pager, multi-pager. The result: students get started faster and learn more – because the environment doesn't get in the way.

[starterguide.dev](https://starterguide.dev)
